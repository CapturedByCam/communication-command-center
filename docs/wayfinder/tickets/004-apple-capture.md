# Use manual Share Sheet capture for Apple Messages in V1

## Question

How should Apple Messages enter the system during the pilot?

## Type

Prototype + grilling

## Status

Closed

## Resolution

Use a Share Sheet/clipboard Shortcut that captures only text Cam explicitly selects. Do not read `~/Library/Messages/chat.db` or run an unattended local collector in V1. Measure capture frequency and friction before opening a Phase 2 bridge decision.
