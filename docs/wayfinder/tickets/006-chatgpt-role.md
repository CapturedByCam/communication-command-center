# Use ChatGPT as the judgment and control layer

## Question

What role should ChatGPT play in the running system?

## Type

Grilling + domain modeling

## Status

Closed

## Resolution

ChatGPT reads connected Gmail, Calendar, Drive, and the command-center Sheet on demand; explains and prioritizes the queue; creates difficult drafts; and applies explicit state changes. Background intake, polling, retries, and canonical state belong to Workspace Studio and Apps Script.
